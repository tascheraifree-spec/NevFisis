# Telegram-бот для видео-стикеров

Бот принимает фото, GIF и короткие видео, превращает их в видео-стикеры Telegram и добавляет в набор пользователя. Фото технически становится неподвижным видео-стикером, поэтому оно может находиться в одном наборе с GIF и видео.

## Запуск на Railway без команд

1. Создайте **приватный** репозиторий на GitHub.
2. Загрузите в него все файлы из этого архива, включая `.env` и `Dockerfile`.
3. Откройте [Railway](https://railway.app/).
4. Нажмите **New Project** → **Deploy from GitHub repo**.
5. Подключите GitHub и выберите созданный приватный репозиторий.
6. Railway автоматически найдёт `Dockerfile`, установит FFmpeg и запустит бота.
7. Когда статус станет **Active**, отправьте фото боту `@Vovaion_bot`.

Никакие команды, домен, порт или отдельный Start Command указывать не нужно.

## Важно

- Репозиторий должен оставаться **Private**, потому что `.env` содержит токен.
- Если репозиторий случайно станет публичным, сразу перевыпустите токен через `@BotFather`.
- Railway должен продолжать держать сервис запущенным; бесплатные лимиты и условия Railway могут меняться.

## Что умеет бот

- фото → неподвижный видео-стикер WEBM;
- GIF → анимированный видео-стикер;
- короткое видео → видео-стикер;
- автоматически создаёт набор и добавляет в него следующие стикеры;
- создаёт следующий набор при заполнении предыдущего.
